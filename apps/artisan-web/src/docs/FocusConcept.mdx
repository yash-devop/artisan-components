# focus vs focus-visible vs focus-within

## It's a CSS pseudo class and mostly useful in Accessibility ( a11y )

### :focus class

<div className="max-w-3xl mt-2">
  `:focus` applies when an element receives focus by any input method.
</div>

<div className="py-3 px-5 mt-6 text-sm text-neutral-700 border border-neutral-300 rounded-xl">
  <p className="text-black font-semibold">NOTE: </p>
  Works with Mouse click , Keyboard navigation using `Tab` `Shift+Tab` , Programmatic focus
  throught JavaScript

</div>

### :focus-visible class

<div className="max-w-3xl mt-2">
`:focus-visible` is a more intelligent version of focus.
It applies focus styles only when the browser determines that the user a visible focus indicator

</div>

<div className="py-3 px-5 mt-6 text-sm text-neutral-700 border border-neutral-300 rounded-xl">
  <p className="text-black font-semibold">NOTE: </p>
  Works with Keyboard navigation , Assistive technologies , It usually does NOT trigger on mouse click.

</div>
